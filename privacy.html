Task List

Privacy Policy

Effective date: November 15, 2026

Task List is a Chrome extension for tasks and lists. This policy explains what data it handles, why, where the data is kept and how you can export or delete it.

In short: Task List stores only what you put into it, so your tasks can sync between your devices. There are no ads, no analytics and no tracking. Your browsing history is not collected, and your data is never sold or shared for any other purpose.

What data Task List handles

  • Your content: lists, sections, labels, tasks (title, description, due date, reminder, priority), comments and files you attach to tasks.
  • Settings: your Task List preferences, such as the theme, the badge and the default reminder.
  • A page you choose to save: when you add a task from a web page (context menu, keyboard shortcut or Quick Add), the task stores that page's address and title. This happens only when you ask for it. Task List does not read other pages or your browsing history.
  • Device information: Task List has no sign-in. Each Chrome profile gets an anonymous device identifier and a label such as “Chrome on macOS”, so you can see and manage the devices connected to your account.
  • Technical data: like any web service, our hosting provider processes IP addresses and request logs to deliver the service, limit abuse and keep it secure.

Task List does not collect names, email addresses, location, health, financial or authentication information, web history, or what you type on websites.

How the data is used

Only to provide Task List's features: to show your tasks, sync them across your connected devices, show reminders and keep your data safe. Your data is not used for advertising or profiling, and is not used to train AI models.

Where the data is stored

  • On your device: a copy of your data is kept in the extension's local storage, so Task List works offline.
  • In the cloud: data is synced through Supabase (servers in the European Union). Attachments are stored in a private storage bucket that only your account can access.
  • Backups: encrypted connections are used to copy the database to a private server operated by the developer every night. Attachment files are copied there weekly.

How long the data is kept

  • Your data is kept for as long as you use Task List.
  • Items you delete are erased from the server 30 days later, together with their attachment files.
  • Database backups are kept for 14 days; copies of deleted attachment files are kept for up to 28 days after they are removed from the weekly copy.

Your choices

  • Export: Settings → Data → Export data downloads a JSON file with all your lists, tasks, comments, settings and the names and sizes of your attachments.
  • Delete: Settings → Account → Delete account permanently deletes your account, all its data and attachment files from the server and from every connected device. Backups containing it expire within 35 days.
  • Notifications are off until you turn them on for a device, and can be turned off again at any time.
  • Uninstalling the extension removes its local data from that Chrome profile.

Sharing

Your data is not sold, rented or shared with third parties. It is processed only by the service providers needed to run Task List (Supabase for hosting), under their data processing terms. It may be disclosed only if required by law.

Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide and improve Task List's single purpose — managing your tasks — and is not transferred, used or sold for any other purpose.

Security

All connections use HTTPS. Access to data is restricted on the server so that each account can reach only its own data. Content you enter is displayed as text, never run as code.

Children

Task List is not directed to children under 13 and does not knowingly collect their data.

Changes

If this policy changes, the new version will be published on this page with a new effective date. Significant changes will also be announced in the extension's Chrome Web Store listing.

Contact

Questions or requests about your data: open an issue on the Task List site repository.
